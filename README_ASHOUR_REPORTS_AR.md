# تقارير عاشور (نقل من موديول أودو)

القائمة: **تقارير عاشور** (أيقونة الرسم البياني في الشريط الجانبي).

| الشاشة | اللي فيها |
|---|---|
| أرباح وخسائر الفروع | عمود لكل فرع + إجمالي الشركة؛ عرض: الفترة الحالية / نفس الفترة السنة اللي فاتت / الميزانية التقديرية / التغيّر % / الانحراف %؛ تبويب النسب (تكلفة المبيعات، الرواتب، الإيجار، هامش الربح…)؛ ملاحظات تلقائية (فروع خاسرة، ارتفاع التكلفة، هبوط الإيراد)؛ حسابات غير مربوطة؛ خيار توزيع مصروفات المركز الرئيسي على الفروع بنسبة الإيراد |
| مبيعات نقاط البيع | مقارنة الفروع بين فترتين، يومي، بالساعة، الأصناف، طرق الدفع، جدول الأصناف حسب الفرع (سنة/شهر/يوم)، مع احتساب «يوم العمل» من ساعة بداية تحددها في الإعدادات، والمرتجعات بتتخصم |
| تقارير المشتريات | مقارنة فترتين بالفئة والصنف (كمية/قيمة/متوسط سعر)، مقارنة الموردين وأحسن سعر، تغيّر الأسعار، كشف حساب الموردين |
| العملاء والتحصيلات | رصيد أول المدة + المبيعات − التحصيلات = الرصيد، نسبة التحصيل، أكبر العملاء |
| إعدادات تقارير عاشور | ربط بنود القائمة بأكواد الحسابات (أطول بادئة تكسب) + ساعة بداية يوم العمل + فرع المركز الرئيسي |

كل تقرير له زر **تصدير Excel** (RTL ومنسّق). الصلاحيات: `ashour_pnl` و`ashour_pos` و`ashour_purchases` و`ashour_customers` و`ashour_settings` (المحاسب يشوف الأربعة الأولى، والإعدادات للمدير).

الإعدادات الافتراضية مظبوطة على شجرة حساباتنا: 41 مبيعات، 42-44 إيرادات أخرى، 51 تكلفة، 52000/52001 رواتب، 520037/520038 إيجار، 520081 إهلاك، وباقي 52 مصروفات تشغيلية. عدّلها لو شجرتك مختلفة.

## اللي ما اتنقلش من أودو
- مجموعات الفروع واستثناءات ربط الحسابات لفرع بعينه (الربط واحد لكل الفروع).
- أوزان توزيع المركز الرئيسي بالسنة (التوزيع هنا بنسبة الإيراد).
- قالب الإكسل المؤسسي للشركة والإيميل الشهري التلقائي ولوحات JS التفاعلية (بدلها جداول وتصدير Excel).
- تصدير PDF لهذه التقارير (Excel فقط).
