# ashour — ديسك توب + سحاب

نفس البرنامج بوضعين:

| | ديسك توب | سحاب (سيرفر) |
|---|---|---|
| التشغيل | `desktop.py` أو ملف `ashour.exe` | `server.py` / Docker |
| الواجهة | نافذة تطبيق على جهازك | متصفح أو تطبيق الأندرويد |
| القاعدة | SQLite محلية (تشتغل من غير إنترنت) | PostgreSQL |
| البيانات | `%LOCALAPPDATA%\ashour` (ويندوز) / `~/.local/share/ashour` | `ERP_HOME` |

## ديسك توب
- من الكود: ويندوز `run_desktop_windows.bat` (بعد `install_windows.bat`) — لينكس/ماك `./start_desktop_linux.sh`.
- جاهز بدون بايثون: من GitHub ← Actions ← **desktop-build** ← Run workflow، ونزّل ملف zip لنظامك من Artifacts، فكّه وشغّل `ashour`.
- النافذة بتفتح بـ Chrome أو Edge أو Brave لو موجود (من غير شريط عناوين)، وإلا بالمتصفح الافتراضي. قفل النافذة بيوقف البرنامج (في وضع المتصفح العادي اقفل البرنامج من الـ console).
- أول تشغيل بيظهر لك كلمة مرور المدير (admin)؛ اتحفظت كمان في `initial_admin_password.txt` داخل مجلد البيانات. غيّرها.
- بيسمع على `127.0.0.1` بس، فمحدش على الشبكة يدخله.

## الربط مع السحاب (مزامنة)
1. على السيرفر السحابي: سجّل الجهاز كفرع: `python sync_admin.py add-node PC01` (بيطلع مفتاح المزامنة).
2. على الجهاز: اعمل ملف `desktop.json` في مجلد البيانات:
```json
{"node_id": "PC01", "hq_url": "https://your-server:8600", "sync_key": "المفتاح"}
```
3. شغّل البرنامج. الشغل بيتسجّل محلي حتى من غير إنترنت وبيتبعت للمركز تلقائيًا (نفس نظام الفروع في README_SERVER_AR.md). تعديل الأصناف والعملاء والحسابات بيتم من المركز.

## حدود
- ما اتجرّبش بناء الـ exe على ويندوز فعليًا من هنا؛ شغّل الـ workflow وقولّي لو فشل.
- الحزمة غير موقّعة، فويندوز SmartScreen ممكن يحذّر أول مرة.
