# ERP Desktop – Executive Dashboard + Multi Units

نظام ERP محلي بواجهة Flet وقاعدة SQLite، مبني على النسخة التنفيذية السابقة.

## أهم الإضافات
- Dashboard تنفيذي وKPI وتقارير الفروع والموازنات.
- شريط جانبي أيقونات وقوائم فرعية قابلة للفتح.
- **وحدات قياس متعددة لكل صنف** مع معامل تحويل إلى الوحدة الأساسية.
- لكل وحدة داخل الصنف: سعر بيع، سعر تكلفة، وباركود اختياري.
- مثال: بيبسي / حبة = 1، كرتونة 18 = 18، كرتونة 24 = 24.
- عند البيع أو الشراء أو حركة المخزون يمكن اختيار الوحدة، والنظام يحوّل الكمية تلقائياً إلى الوحدة الأساسية للمخزون.
- الأسعار يمكن أن تختلف حسب الوحدة.
- الحفاظ على الوحدة الأساسية للمخزون والتقارير لتجنب ازدواجية الرصيد.
- قاعدة البيانات `data/erp.db` مرفقة في هذه النسخة كبداية جديدة تماماً.

## بيانات الدخول الافتراضية
- المستخدم: `admin`
- كلمة المرور: `admin`

## التشغيل على Windows
```powershell
cd C:\erp_desktop
pip install -r requirements.txt
python main.py
```

> هذه النسخة مهيأة للبناء من جديد. إذا كان لديك قاعدة بيانات قديمة، احتفظ بنسخة احتياطية قبل استبدالها.

## Desktop + Cloud
Run locally as a desktop app with `python desktop.py` (or build an exe via the `desktop-build` workflow) and optionally sync with the cloud server. See README_DESKTOP_AR.md.
